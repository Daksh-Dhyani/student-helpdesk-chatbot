# Career guide for BCA Data Science students
General industry guidance, NOT official Chandigarh University information.

## 1. Skills, in this order
Stage 1 - Fundamentals (why: every data job uses these daily)
- Excel: formulas, lookups, pivot tables, charts. Quick answers for any business question.
- Statistics: mean, median, standard deviation, probability, distributions, correlation, basic hypothesis testing. Needed to judge whether a result is real.
- SQL: SELECT, WHERE, GROUP BY, JOIN, subqueries. Data lives in databases, so SQL is the most asked-about skill.
- Python: variables, loops, functions, lists and dictionaries, reading files.
Move on when: you can answer 10 business questions from a table using SQL and write a small Python script without copying.

Stage 2 - Data Analysis (why: this is the actual analyst work)
- NumPy for fast arrays, Pandas for tables.
- Data cleaning: missing values, duplicates, wrong types, outliers.
- Exploratory Data Analysis (EDA): summaries, groupings, patterns, questions.
Move on when: you can take a messy CSV, clean it, and list 5 findings with numbers.

Stage 3 - Visualization (why: people act on charts, not on code)
- Matplotlib and Seaborn for charts in Python.
- Power BI and Tableau for dashboards. Learn one well first (Power BI is a common first choice), then try the other.
Move on when: you can build a dashboard with filters that a non-technical person understands.

Stage 4 - Professional skills (why: this is what separates you from other students)
- Git and GitHub: version control and a public portfolio.
- Data storytelling: problem, finding, recommendation.
- Business analytics: KPIs such as revenue, profit, churn, conversion.
- Basic machine learning: linear and logistic regression, decision trees, train/test split, evaluation. Only after stages 1-3.
Move on when: you can present one project in 3 minutes: the question, the finding and what the business should do.

## 2. The 90-day internship-ready roadmap
Built for students with regular classes. Plan about 1 to 1.5 hours on weekdays and 3 hours on weekends. In exam weeks, cut to 30 minutes a day or pause, then resume. Do not try to skip a week.

Month 1 - Fundamentals (Excel, SQL, Python, Statistics, NumPy, Pandas)
- Week 1: Excel formulas, pivot tables and charts. Assignment: analyse any small sales sheet. Outcome: a one-page summary.
- Week 2: SQL basics (SELECT, WHERE, ORDER BY, GROUP BY). Assignment: 20 practice queries on a sample database. Outcome: saved .sql file.
- Week 3: Python basics and statistics (mean, median, standard deviation). Assignment: small scripts on lists and files. Outcome: 5 scripts.
- Week 4: NumPy and Pandas basics, SQL JOINs. Assignment: load a CSV and answer 10 questions. Outcome: first notebook. Milestone: create your GitHub account and upload it.

Month 2 - Analysis and visualization (Data Cleaning, EDA, Visualization, Power BI)
- Week 5: Data cleaning in Pandas. Assignment: clean a messy dataset and document each step. Outcome: cleaning notebook.
- Week 6: EDA. Assignment: find 5 insights in one dataset. Outcome: EDA notebook with written findings.
- Week 7: Matplotlib, Seaborn and Power BI basics. Assignment: recreate 5 charts in both. Outcome: chart set.
- Week 8: Dashboard development. Assignment: build a 1-page Power BI dashboard with filters. Milestone: Project 1 finished and published on GitHub with a README.

Month 3 - Portfolio and applications (projects, GitHub, LinkedIn, resume, interviews, applications)
- Week 9: Project 2 (different domain, uses SQL + Python). Outcome: second GitHub repository.
- Week 10: Polish READMEs, build the LinkedIn profile, write a one-page resume. Outcome: profile and resume live.
- Week 11: Interview preparation: SQL questions, Pandas questions, explain each project. Outcome: 10 answers practised out loud. Start applying (5 applications this week).
- Week 12: Keep applying (3 to 5 a week), message people on LinkedIn, post one project demo. Milestone: 2 projects, profile, resume and applications sent.
Realistic expectation: this plan makes you ready to apply and interview. It does not guarantee an offer, and results depend on effort and the market.

## 3. GitHub portfolio
- Create an account with a professional username. Create a repository per project (New, name it clearly, tick Add a README).
- Upload: use Add file, Upload files on the website, or git add, git commit, git push.
- Keep it organised: data/ (small samples), notebooks/, src/ or scripts/, README.md, requirements.txt, screenshots/. Never upload passwords or API keys. Do not upload private data.
- A professional README has: title and one-line summary; the business problem; dataset and source; tools used; steps you followed; key findings with numbers; screenshots; how to run it; what you would do next.
- Write commit messages that say what changed. Pin your 2 to 4 best repositories on your profile.
- Project ideas: Retail Sales and Business Intelligence Dashboard; Student Performance Analysis; Customer Churn Analysis; Exploratory Data Analysis using Python; SQL-Based Business Intelligence Project.

## 4. LinkedIn
- Headline: say role and skills, for example "BCA Data Science student | SQL, Python, Power BI | Building data projects".
- About: 3 to 5 short lines: who you are, what you are learning, tools you use, what you are looking for, link to your GitHub.
- Skills: list SQL, Python, Excel, Power BI, Pandas, Statistics, Data Visualization. Add only what you can do.
- Projects: add each project with a one-line result and the GitHub link.
- Certifications: list real ones you completed. They help but projects matter more.
- Featured section: your GitHub and best dashboard.
- Internship experience: list any internship, training or college project work with what you did and the outcome.
- Networking: connect with classmates, seniors, alumni, recruiters and analysts. Send a short note: who you are, what you are learning, one specific question. Do not send the same message to everyone or ask for a job in the first message.
- Share progress: post a project demo or one thing you learned every week or two. Follow companies you like, turn on job alerts for "data analyst intern" and similar titles.

## 5. How to personalise answers
Before giving a roadmap, ask (briefly, one message): course and year, preferred role (data analyst, business analyst, data scientist), current skills, and goal (internship, job, higher studies). Then adapt: skip stages already done, shorten or extend the plan, pick projects to match the role. Remember the answers for later questions in the same chat.
